# CompanyHunter

A thing for finding possible workplaces in these trying times :')
Or rather to find places of intrest to put job applications in.

# What it do?

Right now there is a zsh script for getting company data per city and business category.
List of business categories used by the API can be found here: https://stat.fi/fi/luokitukset/toimiala/

### TODO: 

I want to make a full fledged web service out of this. Maybe add possibility to use AI (Users own lcoal model or a web model like Gemeni or Chat GPT) for narrowing down even more.
